# 本地优先

本地优先不是"没有云"，而是**云端不可用时，本地仍然是完整的**。

## 判断标准

一个工具是不是真的本地优先，看四个问题：

- 断网能不能打开？
- 关掉服务端，数据还在不在？
- 数据能不能被别的软件读？
- 换一台电脑，能不能不经过厂商就把数据带过去？

四个都能，才算。

## 文件即数据库

把元数据写进 Markdown 的 frontmatter，看起来土，但它带来三个好处：

1. 任何编辑器都能看见；
2. 同步盘（坚果云 / WebDAV / Git）天然可用；
3. 十年后文件还在，工具没了也不影响阅读。

代价是更新要"保字节"：不能整篇重新序列化 YAML，否则 git diff 会炸。参见 [[为什么零原生模块]] 里的取舍。

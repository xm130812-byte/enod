# md-reader · UI 设计规范（v1）

> 参照：DSH 内置 Markdown 渲染与设计 token（`--dsw-*` / `--dsw-font-markdown-*`）。
> 目标：**像一份文档，而不是一个仪表盘**。去掉"AI 味"：不做大圆角、不做渐变、不做悬浮抬升、不做毛玻璃。

---

## 1. 视觉原则

| # | 原则 | 具体做法 | 禁止 |
|---|---|---|---|
| 1 | 直角 | 组件圆角 0；仅行内代码/图片 2px | 8/12/16px 圆角、胶囊按钮 |
| 2 | 线而非影 | 用 1px（或 0.5px）边框与底色区分层级 | 投影、光晕、渐变、玻璃拟态 |
| 3 | 单一强调色 | 默认 DSH 蓝 `#4176e6`，可在设置里换 | 多色渐变、彩色图标堆叠 |
| 4 | 排版即品牌 | 标题加粗、行距稳定、边距克制 | 装饰性大标题、居中宣传语 |
| 5 | 密度可选 | comfortable / compact 两档 | 每屏塞太多控件 |
| 6 | 动效克制 | 只做颜色/边框 120ms 过渡 | 位移、缩放、弹跳 |
| 7 | 图标线性 | 1.6px 描边、16–18px | 彩色 emoji、实心大图标 |

## 2. 设计 Token

### 2.4 排版（沿用 DSH Markdown 比例）

| 元素 | 亮色/暗色共用 |
|---|---|
| 正文 | `--reader-font-size`（默认 18px）/ 行高 1.75 |
| h1 | 1.55em / 700 |
| h2 | 1.28em / 700 |
| h3 | 1.12em / 700 |
| h4–h6 | 1em / 600 |
| 段距 | 1em（16px @ 16px） |
| 行内代码 | 0.875em，`--mono`，2px 圆角 |
| 代码块 | 0.82em，`--mono`，1px 边框，2px 圆角 |
| 表格 | 0.9em；无外框；仅行分隔线；`th` 首列左对齐去掉左 padding |
| 引用 | 左边 2px 实线，padding-left 14px，无背景 |
| 分割线 | 0.5px |

字体栈：

```text
UI:   -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif
正文: 衬线 / 无衬线 / 等宽，由用户选（默认无衬线，与 DSH 一致）
代码: "SFMono-Regular", Consolas, "Liberation Mono", Menlo, "Courier New", monospace
```

## 3. 组件规范

### 3.1 顶栏
- 高 44px，白底，1px 底线；左侧品牌字标 `md-reader`（无渐变色块，仅 1px 方框内一个 `m` 字）。
- 中间搜索框：0 圆角、1px 边框、`--bg-soft` 底，右侧 `Ctrl K` 键帽。
- 右侧按钮：32px 方形，1px 透明边框，hover 时显示底。
- 阅读页顶栏：返回箭头、标题（15px/600）、元信息（11.5px/`--fg-3`）、状态选择器（原生 select，方形）、编辑/面板/更多按钮。

### 3.2 书架
- 筛选 tab：**下划线样式**（选中项文字加粗 + 2px 底边），不用胶囊。
- 视图切换：方形分段控件，1px 边框，选中项 `--accent-soft` + 强调色文字。
- 卡片：1px 边框、0 圆角、无投影；hover 仅边框变深；选中时左侧 3px 强调色竖条 + 边框强调。
- 卡片内容：状态点 + 时间（11px）→ 标题 16px/600（最多 2 行）→ 摘要 12.8px/1.6（3 行，compact 2 行）→ 标签 + 字数/批注数。
- 列表：行高 38px，hover 底色，分隔线 0.5px。
- 批量条：`--bg-soft` 底，按钮方形，危险操作靠右。
- **布局记忆**：视图模式 / 排序 / 状态筛选写入 `localStorage`（`mr.shelf.*`），进入文章再返回不会重置成卡片。

### 3.3 阅读器（双布局）

顶栏右侧「布局」按钮在两种布局间切换，选择写入 `config.readerLayout`：

| 布局 | 规则 |
|---|---|
| **文档** | 三栏：目录 220px（右边线）｜正文 | 侧栏 336px（左边线）。正文 `max-width: none`，**撑满中间栏，左右不留白**。 |
| **专注** | 单栏：隐藏目录与侧栏；正文居中 `--reader-measure`（默认 68ch），类似 Typora 的沉浸阅读/写作空间。 |

- 目录项：0 圆角，左侧 2px 透明边；选中为强调色文字 + 2px 左边线，不做底色块。
- 正文：白底、无卡片容器；标题 700，链接无下划线（hover 点状下划线），引用 2px 左边线。
- 批注高亮：4 色半透明底（40%），0 圆角；hover 加深；定位闪烁用 2px 外框而非发光。
- 侧栏 tab：下划线式，计数用小号 `--fg-3`。
- 批注卡：0 圆角、1px 边框；note 为无边框 textarea，focus 时仅底色变化。
- 反链/提及/出链条目：1px 边框、hover 变深；断链用 `--danger` 文字 + 波浪线。

### 3.4 写作
- 编辑区与阅读区同字体；文档布局下同样撑满内容区，专注布局下居中同宽。
- Live Preview：标题加粗、行内代码底色、链接强调色、图片 2px 圆角。
- 保存状态：文字 + 1px 边框小标签，不用胶囊。
- 冲突对话框：左右两栏只读 + 下方可编辑合并结果；0 圆角，1px 边框。

### 3.5 弹层
- 遮罩：`rgba(15,17,21,.38)`，**无模糊**。
- 面板：1px 边框、0 圆角、最大宽 520/920，标题区 1px 底线。
- 输入框：0 圆角、1px 边框、focus 时 1px 强调色 + 无外发光。
- 按钮：0 圆角，主按钮实心强调色，次按钮透明 + 1px 边框。
- Toast：方角、深底（亮色）或浅底（暗色），无阴影。

## 4. 自定义项（设置面板）

| 项 | 取值 | 存储 |
|---|---|---|
| 主题 | 亮 / 暗 / 护眼 / 跟随系统 | `config.theme` + `data-theme` |
| 强调色 | 深蓝 / 青 / 绿 / 朱 / 琥珀 / 石墨 | `config.accent` + `data-accent` |
| 密度 | 舒适 / 紧凑 | `config.density` + `data-density` |
| 阅读布局 | 文档 / 专注 | `config.readerLayout` + `.focus-mode` |
| 正文字体 | 衬线 / 无衬线 / 等宽 | `config.fontFamily` |
| 字号 | 14–30px | `config.fontSize` |
| 行高 | 1.4–2.4 | `config.lineHeight` |
| 行宽 | 40–110ch（专注布局生效） | `config.measureCh` |

书架视图 / 排序 / 状态筛选单独存 `localStorage`（`mr.shelf.view` / `.sort` / `.status`），因为它只属于当前设备。

## 5. 暗色模式

- 不反色，只换 token：背景 `#151517`，面板 `#1b1b1c`，文字 `#f9fafb`。
- 边框用白色 12%/20% 透明度，避免"一层灰一层黑"。
- 链接/按钮用 deepseek-400（`#7aaaff`），对比度 ≥ 4.5:1。
- 代码高亮用 Shiki `github-dark`；行内代码底 `#292929`。
- 批注色在暗色下降低饱和、降低亮度（黄 `#a9862f` / 绿 `#4f8b5c` / 蓝 `#4f7aa8` / 粉 `#a55d74`）。
- 图片灯箱背景 `rgba(8,8,10,.92)`，裁剪为实色。

## 6. 验收清单

- [x] 全站 0 圆角（除行内代码/图片 2px），无 box-shadow（弹层仅 1px 边框）。
- [x] 亮/暗/护眼三套主题下，文字对比度 ≥ 4.5:1。
- [x] 强调色 6 种切换后，链接、主按钮、选中态同步。
- [x] compact 密度下书架卡片 184px、正文不受影响。
- [x] 阅读页与 DSH Markdown 对照：段落 1em 间距、引用 2px 边、表格仅横线、行内代码 2px 圆角。
- [x] 无渐变、无毛玻璃、无悬浮抬升。

---

## 7. 不做的事

- 不做玻璃拟态 / 霓虹发光 / 大圆角卡片。
- 不做彩色渐变按钮、emoji 图标。
- 不做卡片 hover 抬升与缩放。
- 不引入第三方 UI 组件库（保持手写与可控）。

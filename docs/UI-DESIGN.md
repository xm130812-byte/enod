# md-reader · UI 设计规范（v2）

> 参考：MiaoYan 的克制留白与原生三栏，Mole 的深色氛围与工具化信息层级。
> 目标：**像一台桌面阅读器，而不是一个网页仪表盘**。保留直线与细线，但允许小圆角、轻微层次和短动效。

v1 的“全站 0 圆角、无阴影、无位移”是反 AI 味的过度矫正，v2 用它换了三件事：更柔和的纸面底色、更像原生控件的按钮、可感知但不表演的动效。

---

## 1. 视觉原则

| # | 原则 | 做法 |
|---|---|---|
| 1 | 小圆角 | 控件 4–6px，卡片/弹层 8–10px，不使用 16px+ 大圆角胶囊 |
| 2 | 线 + 面 | 以底色分层为主，1px 细线为辅；阴影只用于浮层和 hover |
| 3 | 一个强调色 | 主按钮、链接、选中态共用 `--accent`，不叠彩色图标 |
| 4 | 排版优先 | 系统 UI 字体、紧凑字号、稳定行距；标题不靠装饰 |
| 5 | 工具化图标 | 1.5–1.6px 描边、14–17px；文字只留给需要解释的动作 |
| 6 | 短动效 | 120–260ms，`--ease-out`；只动 opacity / transform / width |
| 7 | 可关闭动效 | `prefers-reduced-motion` 下全部压到 0.001ms |

禁止：玻璃拟态大卡片、霓虹发光、鲜艳渐变按钮、彩色 emoji、悬浮旋转、弹跳。

### 2.3 护眼

`--bg #faf4e8` / `--bg-side #f3ead9` / `--bg-elev #fffaf1` / `--fg #2d261b` / `--fg-3 #7d6d55`，强调色保持琥珀 `#8a5a1f`。

### 2.4 强调色

深蓝 / 青 / 绿 / 朱 / 琥珀 / 石墨六种，由设置面板写入 `data-accent`。石墨是默认推荐的“墨水色”，最接近纸面。

### 2.5 字体与比例

```text
UI:   "Segoe UI Variable Text", "Segoe UI", -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif
标题: "Segoe UI Variable Display", ...
正文: 衬线 / 无衬线 / 等宽，用户可选，默认无衬线
代码: "Cascadia Mono", "SFMono-Regular", Consolas, ...
```

| 元素 | 规格 |
|---|---|
| UI 基准 | 13px / 1.5 |
| 侧栏与列表 | 12px；元信息 9.5–10.5px |
| 顶栏标题 | 13.5px / 600 |
| 卡片标题 | 15px / 600，最多 2 行 |
| 正文 | `--reader-font-size`（默认 15–18px）/ `--reader-line-height` |
| 正文宽度 | `--reader-measure`，居中；中文 35–45 字/行 |
| 代码 | 行内 0.875em；代码块 0.78em |

当正文首个 `H1` 与文档标题完全相同时，阅读视图不重复渲染它；目录同步排除。

## 3. 外壳

### 3.1 一页（默认）

```text
┌──────────────┬──────────────────────────────┐
│ 侧栏 252px    │ 阅读区                        │
│ 品牌 / 收起   │ 52px 顶栏：标题 + 图标工具     │
│ 搜索          │                              │
│ 文件夹｜目录   │ 正文居中                       │
│ 文件树        │                              │
│ 新建 / 统计   │                              │
└──────────────┴──────────────────────────────┘
```

- **收起按钮在侧栏头部右侧**（双左箭头），不再放在阅读器顶栏。
- 收起后侧栏宽度动画到 0，左侧保留 46px 图标导轨：展开、搜索、新建、切换万卷、设置。
- 快捷键 `Ctrl/Cmd+B`；状态写入 `localStorage · mr.simple.collapsed`。
- 侧栏收起时设置 `inert`，不可见内容不接收键盘焦点。
- 搜索是一个侧栏内的“假输入框”按钮，点击打开全局搜索 `Ctrl+K`。
- 文件夹｜目录是两段式分段控件，白色滑块随 `data-active` 平移。
- 文件夹展开用 `grid-template-rows: 0fr → 1fr` 过渡，chevron 旋转 90°。
- 底部只留一个实心“新建”、字数统计、切换与设置图标。

### 3.2 万卷

- 顶栏 54px：品牌、中央搜索框、右侧“一页 / 新建 / 设置”。
- 第二行工具栏：状态分段控件 + 筛选、排序、批量、视图切换。
- 卡片：`--bg-elev` 纸面、1px 细边、8px 圆角；hover 上浮 1px + 轻阴影；selected 左侧 3px 强调条。
- 文件夹视图：左侧 220px 文件夹树 + 右侧文件列表；文件夹行选中用底色，不用左侧竖线。
- 列表视图：有表头（标题 / 路径 / 标签 / 字数 / 更新），行 hover 底色。

### 3.3 阅读器

- 顶栏 52px，透明底 + 细线；返回、标题/元信息、搜索、状态、编辑、专注、更多。
- 编辑/专注/面板切换全部改为图标按钮，文字只保留在 tooltip 与菜单里。
- 目录 214px：`--bg-side` 底，条目 5px 圆角，选中为 `--bg-active` + 左侧 2px 强调条。
- 右侧面板 312px：关闭按钮在面板标签栏右端；关闭后面板宽度动画到 0，并在右缘出现竖向“批注”把手。
- `Ctrl/Cmd+Shift+B` 切换右侧面板；状态写入 `localStorage · mr.reader.panel`。
- 正文居中、`--reader-measure` 宽；行内代码 3px 圆角、代码块 6px 圆角。
- 阅读进度是 2px 顶部线，宽度 160ms 线性过渡；右下角进度胶囊默认 72% 不透明度。
- **专注模式**：目录与右侧面板收窄到 0（不是瞬间 `display:none`），正文居中；收起内容 `inert`。
- **沉浸模式**：隐藏顶栏、目录、面板、进度与右下角进度胶囊；只留正文，右上角出现“退出沉浸”，`Esc` 退出。
- `Esc` 优先级：关文内查找 → 关菜单 → 清选区 → 退沉浸 → 退编辑 → 退专注 → 返回书架。
- 沉浸模式、切换到一页、删除等低频动作收进“更多”菜单。

## 4. 动效

| 场景 | 动效 | 时长 |
|---|---|---|
| 视图进入 | 透明度 + 3px 上移 | 260ms |
| 正文换文档 | 透明度 + 5px 上移 | 300ms |
| 侧栏 / 右侧面板 | width + opacity | 260ms |
| 文件夹展开 | grid rows + opacity + chevron 90° | 180ms |
| 分段控件 | 白色滑块 translateX | 180ms |
| 目录选中 | 背景 + 左侧 2px 条 scaleY | 180ms |
| 卡片 hover | translateY(-1px) + shadow | 180ms |
| 菜单 | 透明 + scale(.985) | 140ms |
| 搜索面板 | 上移 8px + scale(.99) | 180ms |
| 弹窗 | 上移 8px + scale(.985) | 200ms |
| Toast | 上移 8px 进入，离场 160ms 下移淡出 | 220/160ms |
| 灯箱 | 图片 scale(.97) → 1 | 220ms |

统一曲线：

```css
--ease: cubic-bezier(.22,.61,.36,1);
--ease-out: cubic-bezier(.16,1,.3,1);
--dur: 180ms;
--dur-slow: 260ms;
```

`prefers-reduced-motion: reduce` 下全部关闭；`scrollIntoView({ behavior: 'smooth' })` 由脚本侧保持，但 CSS 过渡归零。

## 6. 验收清单

- [x] 侧栏收起按钮位于侧栏内，`Ctrl+B` 可用，收起后有 46px 导轨。
- [x] 右侧面板收起按钮位于面板内，`Ctrl+Shift+B` 可用，收起后有边缘把手。
- [x] 侧栏、面板、文件夹、抽屉均有宽度/高度过渡，收起内容 `inert`。
- [x] 亮 / 暗 / 护眼三套主题下正文对比度 ≥ 4.5:1。
- [x] 卡片、弹层、菜单有短动效；搜索/弹窗无明显卡顿。
- [x] `prefers-reduced-motion` 下无动画。
- [x] 正文首个标题与文档标题重复时不再显示两遍。
- [x] 一页 / 万卷 / 书架视图切换不丢失滚动与筛选。
- [x] 全站无大圆角、无大面积渐变、无彩色图标。

## 7. 不做的事

- 不模拟 macOS 红绿灯、不做假窗口边框（当前是浏览器承载）。
- 不做玻璃拟态大卡片、霓虹发光、3D 翻转。
- 不引入第三方 UI 组件库；图标仍由手写 `Icons.tsx` 提供。
